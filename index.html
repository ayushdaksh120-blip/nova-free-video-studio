Documentation

  1. Clone: git clone https://github.com/ayushdaksh120-blip/nova-free-video-studio.git
  2. Enter: cd nova-free-video-studio
  3. Serve: python -m http.server 9000
  4. Open: http://localhost:9000

Android / Termux

  1. pkg update -y && pkg install -y python git
  2. git clone https://github.com/ayushdaksh120-blip/nova-free-video-studio.git
  3. cd nova-free-video-studio && python -m http.server 9000
  4. Open in Chrome/Firefox: http://localhost:9000

This project is static. No build step, no database, no server required. Secrets are never stored in the repo.
