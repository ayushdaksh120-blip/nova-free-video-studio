Help

Run on Android (Termux)

  1. Install Termux from F-Droid.
  2. Run pkg update -y && pkg install -y python
  3. Copy this project folder into Termux or clone it.
  4. cd /path/to/project && python -m http.server 8000
  5. Open http://localhost:8000 in Chrome/Firefox.

For a production-style server: npx serve . or php -S localhost:8000. Get a free Pollinations key: enter.pollinations.ai/keys.
