How it works

Independent engine architecture

  1. Prompt parsing: keywords select a scene engine and palette.
  2. Deterministic seed: the same prompt and seed produce the same motion.
  3. Real-time rasterization: canvas compositing, gradients, particles, fields, typography.
  4. Genuine capture: MediaRecorder encodes actual rendered frames into WebM.
  5. Local persistence: IndexedDB stores videos for offline gallery use.

This is a self-contained owner-built generator. It does not call Pollinations, Kling, Runway, Replicate, Hugging Face, or any paid API.
